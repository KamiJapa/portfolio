# Daniel Murakami — Portfólio

Site estático em português brasileiro, feito com HTML5, Tailwind CSS via CDN, CSS e JavaScript puro.

Abra `index.html` no navegador. Não exige instalação nem compilação. O Tailwind e a fonte Inter são carregados pela internet; o CSS local preserva a estrutura e oferece fonte alternativa se esses recursos estiverem indisponíveis.

## Personalização

- Conteúdo e links do WhatsApp: `index.html`.
- Cores, espaçamentos e responsividade: `styles.css`.
- Menu, navegação ativa e animações: `script.js`.
- Referência visual aprovada: `design/conceito-aprovado.png`.
- Foto futura: substitua o conteúdo de `.portrait` por uma imagem com texto alternativo e adapte o enquadramento no CSS.
- Projetos: adicionar a seção e seu link na navegação quando houver trabalhos reais.
